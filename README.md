# PureShine Auto Wash & Detailing — GitHub Pages

Upload `index.html`, `hero.png`, and `.nojekyll` to the root of your GitHub repository. In the repository Settings → Pages, select **Deploy from a branch**, your main branch, and the **/(root)** folder. GitHub will display the public Pages URL once it publishes.

This package restores the original dark teal website design. The Book Now buttons open the existing booking calendar hosted at https://pureshine-autowash.milky-ibis-4901.chatgpt.site/book. The private bookings app remains at https://pureshine-autowash.milky-ibis-4901.chatgpt.site/bookings. Both need the existing shared booking service; GitHub Pages alone cannot run the database or admin sign-in.

Do not put customer booking records, passwords, or secret tokens in your GitHub repository.
